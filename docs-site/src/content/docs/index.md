---
title: GitHub token broker
---

The broker exchanges a pod's projected Kubernetes credential for a short-lived GitHub installation token scoped to its assigned repository and role. See the [token broker reference](https://github.com/julie-ng/ai-native-sdlc/blob/main/architecture/reference/token-broker.md) for the design, or the [GitHub repository](https://github.com/julie-ng/ai-native-sdlc-github-broker) for the implementation.
